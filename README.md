# Работа Касимова Василя
#  Проект «Pong Levitation» на языке OpenScad


Модель для 3D-печати сопла с чехлом для вентилятора из экспериментатльного набора
альтернативных источников энергии leXsolar, которая используется для проведения физического опыта
по левитации шарика от Пинг-понга, настольный тенниса, в потоке воздуха. Ускорение поката воздуха 
выполняется с помощью сопла Лаваля.
